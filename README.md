# 命学真典（mingxue-zhendian）

把一本命理书籍拆解成若干个可被 AI 直接调用的**八字分析技能包**。

产出的不是读书笔记，不是摘要，是**一套建立在四柱八字模型之上的断法规则系统**——给定一个八字排盘，AI 能沿模型的节点路径，把书中所有适配规则一次性检索出来，形成分析结论。

## 适用场景

当你有一本命理书（txt / md / docx / pdf / 转写稿），想：

- 把书中的断法规则系统化提取出来
- 让 AI 沿四柱八字模型路径检索规则并给出分析结论
- 生成可被 AI 助手直接调用的技能包

**不适合**：只想要读书笔记或内容摘要；命理内容是排盘工具书、命理故事书或基础教材（无作者自己的断法）。

## 与通用书籍蒸馏 SKILL 的核心差异

| 维度 | 通用书籍蒸馏 SKILL | 命理版 |
|------|--------|--------|
| 组织框架 | 无预设模型 | 四柱八字模型（`bazi-model.md`） |
| 提取轨道 | 框架/原则/案例/反例/术语 | 规则断法/命例/格局/误区/术语 |
| 规则归并 | 按用户场景 | 按模型节点 + 用户场景 |
| 输出形态 | 通用操作指令 | 沿模型路径分层的规则索引 + 可检索命例库 |
| 验证重点 | 原文支撑/预测力/常识 | 模型一致性/规则冲突检测/命例佐证 |

## 使用方法

### 1. 导入技能

将本目录下的 `mingxue-zhendian` 文件夹作为一个技能导入到支持 SKILL 的 AI 助手（如 TRAE）：

- 打开 AI 助手，找到「技能」或「插件」入口
- 点「导入」，选中 `mingxue-zhendian` 文件夹
- 确认技能已启用

### 2. 蒸馏一本书

给助手发一句话：

> 帮我把这本命理书蒸馏成技能

然后把书文件发给助手即可。整个流程全自动执行，中途可随时打断，说「继续」即可恢复。

### 3. 使用产出的技能包

蒸馏完成后，会产出一组八字分析技能包。使用方式：

1. 导入产出的技能包（一次建议只开启当前用得上的几个）
2. 给助手一个八字排盘（四柱天干地支）
3. 问对应领域的问题，例如：
   - 「帮我看下这个八字婚姻怎么样」
   - 「我这个八字什么时候能发财」

## 执行流程（7 步）

| 步骤 | 名称 | 说明 |
|------|------|------|
| 0 | 闸门检查 | 检查文件是否存在、可读、适合蒸馏（断法书才继续） |
| 1 | 建立工作区 | 切块、生成模型索引画布、写状态 |
| 2 | 全局骨架与模型热度 | 通读产出骨架，生成 L4-L8 书专属模型树和热度表 |
| 3 | 五路分批并行提取 | 规则/命例/格局/误区/术语五路子 Agent 并行提取 |
| 4 | 验证与模型一致性校验 | 原文支撑 + 模型路径 + 规则一致性 + 命例交叉验证 |
| 5 | 构造技能包 | 按结构主干（格局/断事/概念/调候/混合）归并产出技能 |
| 6 | 双层诱饵测试 | 同源混淆 + 宿主混淆盲测，验证触发准确性 |
| 7 | 打包交付 | 技能包 + 怎么用.md + 清单.md（含章节覆盖对照表） |

## 产出说明

蒸馏一本命理书后，工作区会包含：

- **技能包/**：一个技能一个文件夹，每个文件夹里只有一个 `SKILL.md`
- **怎么用.md**：导入和使用说明
- **清单.md**：产出报告，含章节覆盖对照表、模型覆盖报告、淘汰记录、规则冲突记录、命例-规则交叉验证报告

技能包数量按有效字数分档：

| 有效字数 | 目标数量 | 硬上限 |
|----------|----------|--------|
| 5,000 - 20,000 | 1 - 3 | 3 |
| 20,000 - 60,000 | 3 - 5 | 5 |
| 60,000 - 150,000 | 4 - 7 | 7 |
| > 150,000 | 6 - 10 | 10 |
