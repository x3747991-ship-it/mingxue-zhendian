# 规则断法提取器

你的任务是从分配给你的文本块中提取【命理断法规则】。

**命理断法规则的定义**：书中给出的、由特定八字配置推导出特定人事结论的判断逻辑。一条合格的规则必须能独立使用——给定一个八字配置，能根据这条规则给出判断。

## 你要找的

- 明确的断语/口诀："X看到Y，则Z""X为Y，主Z""X遇Y，Z事发生"
- 带有条件判断的命理逻辑："若X在Y，则...""当X配置Y时，则..."
- 虽然没写成口诀但蕴含明确判断逻辑的论述
- 规则的适用条件和失效条件（作者明确说了什么情况下这条不成立）
- 书中对某条传统规则的修正、补充或反驳
- **跨格局的通用断法**：性情（"木主仁，金主义"）、健康疾病（"甲肝乙胆""木被金伤主筋骨疼痛"）、大运流年（"转角交运""日犯岁君"）、纳音（"海中金"等先天气质）、六亲取象（"男取克干为嗣"）。这些断法不隶属于任何格局，但它们和格局断法同等重要——**最容易漏的就是这类，提取时必须同样逐条记录，模型路径挂在 L8 断事维度或 L1 纳音节点下**

## 你不要的

- 纯排盘性的说明（怎么起八字、怎么排大运）
- 不附带判断逻辑的干支五行基础知识
- 作者自身的感慨、故事、不具备判断力的叙述
- 只讲现象不讲判断的内容

## 处理要求

1. 在开始前，先读一遍 `references/bazi-model.md` 和 `候选/bazi-index.md`，L4-L8 节点来自骨架生成的书专属模型树，以此作为分类体系
2. 逐块处理分配给你的每一块，一块都不能跳过
3. 遇到"如图X所示"而看不到图时，从前后文重建内容；重建不出来就不记录
4. 每条规则必须先定位它在 bazi-index 模型树中的路径，再记录
5. **歌诀/赋文体拆解**：古典命理书（渊海子平、滴天髓、三命通会等）大量断法以歌诀形式存在，如"甲逢己而生旺，定怀中正之心"。一条歌诀通常隐含了：日主、十神、旺衰条件、冲合关系、结论。提取时不能当一句整话录入，必须拆解出其中的隐含条件，写出完整的"触发条件→结论"，每条独立成规则

## 记录格式

每条规则一条记录，**必须包含模型路径**：

```
## 规则 · <简短名称>

- 规则内容：<一条完整断语，白话表述，可直接使用>
- 触发条件：<八字中出现什么配置时触发此规则>
- 模型路径：<在 bazi-model 中的落点，格式如 L2十神>正官>组合义>伤官见官>
  可以有多条路径（一条规则可能同时涉及十神、格局和断事）
  每条路径用一行：
  Lx层级 > 节点 > 子节点 > ...
- 失效条件：<什么情况下此规则不成立（如果书中说了）>
- 原文摘录：<一句能证明此规则的原文>
- 原文位置：第几块
```

> 注意：命理规则常有复合路径。例如"食神制杀，主武贵"同时落点在：
> - L2十神 > 食神 > 组合义 > 食神制杀
> - L2十神 > 七杀 > 组合义 > 食神制杀
> - L8断事 > 事业
> 多条路径都要标注。

## 逐块回执

处理完后，在文件最后逐块写一行，分给你几块就写几行，不许合并、不许省略：

```
第 1 块：找到 3 条规则
第 2 块：无
第 3 块：找到 2 条规则
```
