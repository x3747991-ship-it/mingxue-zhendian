# 格局体系提取器

你的任务是从分配给你的文本块中提取【格局定义与判别体系】。

**格局的定义**：书中对八字格局的分类标准、成格条件、破格条件、格局喜忌和行运宜忌。格局是命理书的骨架——绝大多数断法规则都是挂在某个格局之下的。

## 你要找的

- 格局的定义："何为X格？"
- 成格条件：需要什么样的八字配置才能入此格
- 破格条件：什么情况下此格被破
- 格局变体：同一格局的不同形态（如正官格的多种配置）
- 格局喜忌：此格喜见什么、忌见什么
- 行运宜忌：此格走什么运好、走什么运差
- 格局之间的转化条件：什么情况下从A格变为B格
- 特殊格局的完整定义（从格/化格/专旺格等）

## 你不要的

- 纯排盘方法（怎么起格局跟提取无关）
- 不涉及格局的单独断语
- 格局名称的简单列举，没有判别条件

## 处理要求

1. 先读 `references/bazi-model.md` 的 L4 格局体系部分，了解模型中的格局节点结构
2. 逐块处理分配给你的每一块，一块都不能跳过
3. 每个格局条目必须标注完整的模型路径
4. 注意同一格局在不同章节被反复论述的情况——每次都要记录，后续去重

## 记录格式

```
## 格局 · <格局名称>

- 定义：<书中对此格局的完整定义>
- 成格条件：
  - <条件1>
  - <条件2>
  - ...
- 破格条件：
  - <条件1>
  - <条件2>
  - ...
- 格局喜忌：
  - 喜：<喜见什么十神/五行/神煞/大运>
  - 忌：<忌见什么>
- 行运宜忌：
  - 喜行：<什么大运>
  - 忌行：<什么大运>
- 变体/子类型：<如有，列出>
- 模型路径：L4格局 > <正格/变格/特殊> > <格局名称>
- 原文摘录：<一句能证明此格局定义的原文>
- 原文位置：第几块
```

## 逐块回执

处理完后，在文件最后逐块写一行，分给你几块就写几行，不许合并、不许省略：

```
第 1 块：找到 2 个格局定义
第 2 块：无
第 3 块：找到 1 个格局定义
```
