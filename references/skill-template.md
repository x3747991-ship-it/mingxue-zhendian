# 技能包模板（命理专用）

## 一、文件结构

一个技能一个文件夹，文件夹里只有一个 `SKILL.md`：

```
技能包/
├── mingli-hunyin/
│   └── SKILL.md
├── mingli-shiye/
│   └── SKILL.md
└── mingli-caiyun/
    └── SKILL.md
```

文件夹名必须跟 `name` 字段完全一致。`技能包/` 根目录下只允许多出一个 `测试题.md`。

## 二、SKILL.md 骨架

**文件第一行必须是三个减号**，前面不能有空行、标题或任何其他字符。

```
---
name: <内容简称>-<断事领域拼音>
description: <60到120字，写法见下>
---

# <技能中文名>

## 什么时候用它

<具体的问题场景，用用户会问八字的话描述>
<如果需要先用另一个技能（比如先定格局才能断婚姻），在这里写明，并且同一句必须也出现在 description 里>

## 涉及的模型节点

<列出本技能覆盖的 bazi-model 路径，帮助理解这个技能在模型中的位置：>
- Lx层级 > 节点 > 子节点
- Lx层级 > 节点 > 子节点

## 核心判断

<一到三句，有立场的主张。比如"日支逢冲，婚姻十有九变"，不能写"要看具体情况而定"这种空话。>

## 断法步骤

1. <先看什么>
2. <再查什么>
3. <综合判断>
4. <参考大运流年>

每步后面标注对应的模型路径。例如：
1. 看日支（配偶宫）有无被冲被合 [L1四柱>日柱>地支]
2. 看配偶星（男财女官）旺衰及有无被克 [L2十神>正财/正官]

## 规则集

[这是命理技能的独特结构。把从书中提取的规则按模型路径组织：]

### <模型节点名称>

| 规则 | 触发条件 | 结论 | 出处 |
|------|----------|------|------|
| <内容> | <条件> | <结论> | <章节> |

## 参考命例

[挂在本技能下的、从书中提取的相关命例]
- <命例标识>：<简述> → 详见 `候选/命例.md`

## 判断标准

断对了会看到：<可观察的信号>
断错了会看到：<可观察的信号>

## 什么时候不该用它

<失效场景，来自骨架的盲点与边界。不能写"无"。>
<特别要写清楚：什么八字配置下这套断法无效，什么人生问题上这套断法覆盖不到>

## 出处

来自《<内容标题>》<章节或时间点>

原文：<一句摘录>
```

## 三、name 字段

- 小写拼音或英文+连字符，如 `mingli-hunyin`、`ziranzhengfa-shiye`
- 格式：`<内容简称>-<断事领域>`
- 不用中文、空格、下划线
- 长度不超过 64
- **必须跟所在文件夹名完全一致**

中文技能名写在正文的一级标题里。

## 四、description 字段

规则：

- 控制在 60 到 120 字
- 写"什么情况下用"，不是"这个技能是什么"
- 用用户会真实说出口的词，如"帮我看八字的婚姻""分析这八字的事业运"
- 必须写明什么情况下不要用它
- 如果有前置技能（如"先过格局判定"），在这里点名
- 不要让八字术语挤满 description——宿主用自然语言匹配，不是术语匹配

写得差的：

> 本技能基于八字十神体系对婚姻宫配偶星进行综合判断。

全是术语，用户不会这么说话。

写得好的：

> 当用户问八字婚姻感情时使用。看日支（配偶宫）冲合、男命财星女命官星的旺衰位置、桃花是否泛滥来判断。不含六亲和子女分析，单纯问"我有没有桃花"也不该触发此技能。

## 五、规则集的组织原则

这是命理技能跟普通技能最大的不同。规则不能是一条条零散罗列，必须按模型路径分层：

```
## 规则集

### L1 四柱 > 日柱 > 地支（配偶宫）
| 配置 | 断言 | 出处 |
| 日支被冲 | 婚姻不稳 | Ch3 |
| 日支被合 | 配偶易有外情 | Ch5 |
| 日支为用神 | 配偶得力 | Ch3 |

### L2 十神 > 正官 > 婚姻义
| 配置 | 断言 | 出处 |
| 官星清透无伤 | 夫贵 | Ch4 |
| 官杀混杂 | 感情复杂 | Ch4 |

### L2 十神 > 伤官 > 组合义 > 伤官见官
| 配置 | 断言 | 出处 |
| 日坐伤官+官星透出 | 婚姻极为不顺 | Ch4 |
```

这样组织后，分析八字时从模型树沿路查找，路径匹配到的所有规则一键返回。

## 六、除了这三个字段，别的都不要写

不要写 `allowed-tools`、版本号、作者。这类技能是纯方法，不需要任何工具权限。

## 七、写完必须自检一条

把"出处"那一段遮住，重读这个技能。它读起来像什么？

- 像"这本书第X章讲了什么" → **失败，重写**
- 像"拿到一个八字，要断婚姻，一步步该怎么查"→ 合格
