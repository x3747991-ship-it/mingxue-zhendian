# 误区反例提取器（命理专用）

你的任务是从分配给你的文本块中提取【误区、反例与规则失效场景】。

**反例的定义**：作者明确指出的常犯错误、常见误判、或者某条规则失灵的情况。命理书中，反例通常以"很多人以为X就Y，其实不对""遇到X配置，常规断法Z不成立"的形式出现。

## 你要找的

- 作者纠正的常见误判
- 作者承认某条规则在特定八字配置下不成立
- 书中给出的错误命例，以及错误的原因
- 作者对某个流行命理观点的反驳
- 同一条规则在不同格局下的相反结论

## 你不要的

- 纯粹的行文抱怨（"现在的命理师乱看"），没有具体所指
- 没有说明为什么错的否定

## 处理要求

1. 逐块处理分配给你的每一块，一块都不能跳过
2. 每条反例/误区必须标注：它是在给哪条规则或哪种断法划边界
3. 遇到"如图X所示"而看不到图时，从前后文重建内容

## 记录格式

```
## 反例 · <一句话概括>

- 常见错误：<很多人怎么做/怎么断>
- 错在哪：<作者指出的错误原因>
- 正确做法：<作者给出的正确判断>
- 关联规则：<这个反例是在给哪条规则划边界（引用规则的简短名称）>
- 失效条件：<什么八字配置下常规规则不成立>
- 原文摘录：<一句原文>
- 原文位置：第几块
```

## 逐块回执

处理完后，在文件最后逐块写一行，分给你几块就写几行，不许合并、不许省略：

```
第 1 块：找到 2 个反例
第 2 块：无
第 3 块：找到 1 个反例
```
